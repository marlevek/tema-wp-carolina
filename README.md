# Tema Carolina Cunha Levek

Tema WordPress desenvolvido para o blog da psicóloga Carolina Cunha Levek, com identidade visual acolhedora, editorial e alinhada ao site principal.

![Preview do tema](./screenshot.png)

## Visão geral

Este repositório contém o tema do blog em WordPress, com foco em:

- navegação própria para o blog
- home editorial com posts recentes
- cards de artigos com imagem destacada, data, resumo e link de leitura
- páginas de post individual com leitura confortável
- responsividade para desktop e mobile
- integração visual com o site institucional da Carolina

## Requisitos

- WordPress instalado
- acesso à pasta `wp-content/themes/`

## Instalação

1. Clone este repositório ou copie a pasta do tema para:

```text
wp-content/themes/tema-carolina
```

2. No painel do WordPress, vá em `Aparência > Temas`.
3. Ative o tema `Tema Carolina`.

## Recursos do tema

- menu próprio do blog com suporte a `wp_nav_menu`
- fallback de navegação coerente com a experiência editorial
- listagem de posts com thumb padronizada para cards
- categorias tratadas de forma mais elegante
- header e footer refinados para o contexto do blog
- suporte a imagem destacada

## Observações

- Este repositório contém apenas o tema, não a instalação completa do WordPress.
- Arquivos auxiliares e materiais de processo foram excluídos do versionamento.
